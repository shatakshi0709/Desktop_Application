# SpendWise – Personal Finance Tracker

SpendWise is a desktop expense-tracking application built with Electron, HTML, CSS, and JavaScript. It helps users manage their income, track expenses, and monitor their financial activity.

## Features
- User registration and secure login
- Track income and expenses
- Dashboard with financial summaries
- Income vs. expenses chart
- Category-wise expense donut chart
- Monthly spending breakdown
- Supabase database integration

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Desktop: Electron
- Database and Authentication: Supabase (PostgreSQL)

## Run Locally
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Configure your Supabase environment variables in `.env`.
4. Start the application:
   ```bash
   npm start
   ```

## Purpose
SpendWise aims to make personal finance management simple, organized, and user-friendly.
